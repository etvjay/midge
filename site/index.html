01 · The problem

Deciding together with money on the line is hard

A fund splitting a pot, a DAO picking a quote, a team of AI agents buying together. Today there are three ways to do it, and each one breaks something.

The fine print: Do it in public

In our public auction on testnet, a watcher who bid at the last moment took the lot from the bidder who valued it most.

The fine print: Trust an organizer

In our test with an organizer, an observer could read every backer's amount, and nothing stops the organizer leaving with the pot.

The fine print: Trust a black box

Secure hardware has had real attacks. Midge assumes it can fail, and limits what a failure can pay.

02 · How it works

Every group gets a room, rules and an exit

Three parts, each checking the one before it. Nobody holds the money, nobody sees the bids, and nobody can lock anyone in.

The fine print: The room decides in private

The room runs inside secure hardware: either an AI model on NEAR AI Cloud, or our own program on Phala. Anyone can check which code it runs.

The fine print: The rules are public

How much can leave is paced by time: at most the agreed share per window, and a window is twice the group's exit timer. With a short timer most of a group could still leave within minutes, so groups choose their timer on purpose; the contract refuses one under 10 blocks.

The fine print: Anyone can leave

The exit opens after the group's exit timer or its deadline. While a payout is in flight, exits wait; anyone can finish a stuck payout after about two minutes.

03 · Who uses it

Any group, on one shared network

People, DAOs, companies and AI agents join the same way, with a NEAR account. These four have run on testnet next to a public version.

The fine print: Auctions and token sales

Sealing hides the losing bids, not everything: the winner and the price are public, and every bidder locks the same deposit.

The fine print: Voting

Run on testnet next to an open poll and a multisig. The payout is public; who voted which way is not.

The fine print: Paying people

The amounts are public on NEAR. With distinct, unchanged salaries an observer can still link a person across months by amount.

The fine print: Investing together

Midge hides each backer's amount only when everyone deposits the same; if each pays their own amount, it is public when the round settles.

04 · AI agents

A hijacked AI agent still can't take the money

An agent can be given a key that does one thing only: take its owner's money back out. We tricked such an agent into trying everything. Every attempt was refused.

The fine print: Send money to the attacker

Refused by the key itself, which can only do one thing. The key limits what a fooled agent can do; it does not stop the agent from being fooled.

The fine print: Call another contract

05 · Under the hood

Private work in secure hardware. Final say on NEAR

Three systems work together, and each one checks the one before it. A bad answer gets stopped at the next step.

The fine print: NEAR AI Cloud

Your browser can ask NEAR AI Cloud to prove what it runs, with a random number it picks, and check the answer.

The fine print: Our program on Phala

Its code and settings are fixed and checkable; the version that ran was checked on real secure hardware.

The fine print: The contract on NEAR

Its exact version can be read straight from NEAR by your browser.

      07 · Try it

      Three ways in

      Check everything, offline

      One command runs every test and check. No keys, no money.

      git clone https://github.com/etvjay/midge && cd midge npm install && npm run verify

      Run your own copy

      Make a free testnet account, deploy your own contract and run real rounds and attacks against it.

      node scripts/setup-testnet-account.js npm run build:wasm node scripts/lab-env.mjs bootstrap node lab/run.js --tier testnet
