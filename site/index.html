Midge · on NEAR

A network of private rooms
with public rules

On Midge, any group forms a syndicate: people, a DAO, an institution or a swarm of AI agents. Members decide together in private. What the group can do with its money is fixed in public, and if the room stops, every member can walk out with their own share.

01 · Why

Acting together on a public chain leaves three bad options

Funds, DAOs, lending desks and agent swarms all need to decide things together: who bids what, how to split a pot, which quote wins. Today each way of doing it gives something up.

Do it in public

Every bid, size and vote is visible before it executes. Others copy it or trade against it.

Hand someone the keys

An organizer holds the money off-chain. If they fail, leave or are hacked, the group loses it.

Trust a secure box that can sign anything

Secure hardware keeps the decision private, but if the contract pays whatever the box signs, one flaw drains the pool.

Midge keeps all three properties at once: the decision stays private, nobody holds the money, and nobody can trap it.

02 · How it works

Every syndicate is a room, rules and an exit

The same three parts make up every syndicate on the network, whatever the group is doing.

The room

Members decide in private

Each member seals their bid so only the room can open it. The room adds the bids up and lets out only the result. Whoever runs the machine sees sealed data, nothing else.

The room runs inside secure hardware (a TEE), which keeps what it processes hidden and proves which code it runs. There are two kinds: an attested AI model on NEAR AI Cloud, and our own program on a Phala confidential machine.

Both live

The rules

What the group can do is fixed in public

When the group forms, its rules go into a contract on NEAR: who may be paid, how much per round, and until when. Every member agrees to exactly those rules when they put money in, and they can never change.

A payout outside them is refused, even if the room signed it. The same signature can never be used twice.

Live · attacks rejected on chain

The exit

Anyone can leave on their own

If the room stops, crashes or disappears, a timer runs. When it ends, any member takes back exactly their own share, straight from the contract, without anyone's permission and without touching anyone else's money.

Live · exact refunds checked

03 · Syndicates

04 · The network

One contract. Many syndicates

A single contract on NEAR hosts every syndicate, each with its own rules. Anyone can list them, a member can find all of theirs, and one agent can sit in several at once.

…syndicates on the testnet contract right now

Today the network is discovery and bookkeeping: syndicates do not yet invite, rate or build on each other.

AI agents

Live

A hijacked agent still cannot take the money

An agent can be given a key that does exactly one thing: take its owner's money back out of a syndicate. We handed such an agent a support ticket that told it to send everything to an attacker. Every attempt was refused: eight by NEAR before they ran, because the key does not allow them, and an early exit by the contract. The same transfer from an agent holding a full key went through.

Live · 9 of 9 attempts refused

This bounds a compromised agent by what its key can do. It does not claim that an AI model resists being misled.

07 · Architecture

    
Private work runs inside secure hardware. Every result settles on NEAR

    

      

        
Midge's private work runs inside two kinds of secure hardware, on NEAR AI Cloud and in our own program on Phala, and every result is settled and enforced on NEAR.

        

          
NEAR AI Cloud
An attested AI model helps the group decide, for example how to split an amount. It only sees what it is given, never an individual bid.

          
Our program on Phala
The group's sealed bids are opened and added up exactly, and the settlement is signed only if it fits the total. The keys stay inside.

          
NEAR
The contract settles the result and checks it against the group's rules. Anything outside them is refused, and any member can take their share back if the private side stops.

        

        
Each part liveAll three in one run: pending

        
The NEAR AI and Phala parts are each proven live, and NEAR AI's answer has been settled on NEAR through a Roost running locally. A single run with the Roost on Phala and the model on NEAR AI has not been recorded yet.

      11 · Try it

      Check everything, offline
      
        
      One command runs every check in the repository: the contract tests, every interface and the recorded evidence. No keys, no money.
      
        
      git clone https://github.com/etvjay/midge && cd midge
npm install && npm run verify
      
      
      
      
      
        
      Run your own copy on testnet
      
        
      Creates a free testnet account from NEAR's testnet helper, builds and deploys your own copy of the contract (the build reproduces our code hash), then runs real rounds and attacks against it. Needs Node and Rust; costs only free testnet NEAR.
      
        
      node scripts/setup-testnet-account.js
npm run build:wasm
node scripts/lab-env.mjs bootstrap
node lab/run.js --tier testnet
