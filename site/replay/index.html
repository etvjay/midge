These are recorded runs of the room on real secure hardware, each settled on a NEAR testnet contract. Your browser re-checks every log from its raw events, and nothing is sent anywhere. A check that cannot run says so, and never passes by default.

What this page does not prove

  • A log that checks out was not changed after it was written. It does not show the events were honestly produced, so the transaction hashes in each run are linked for you to open on the explorer.
  • The attestation of the hardware is in each run as a recorded event. Checking the Intel certificate chain needs the verifier in npm run verify:tee, which this page does not repeat.
  • Amounts and addresses are public on NEAR. What the paper trail hides is who each address belongs to, and a person with a unique and unchanged amount can still be matched across months.
  • One operator ran every account in these tests. No independent operators have been shown, and nothing here runs on mainnet.
